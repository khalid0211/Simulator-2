# Technical Specification: Autonomous AI Portfolio Optimizer

## 1. Objective & Architecture Overview
The **Autonomous AI Portfolio Optimizer** plays the 60-month project portfolio simulation in **Custom Mode** to discover the optimal sequence of monthly decisions for a given scenario and its **exact deterministic seed**, tailored to the user's priority ranking of four core objectives:

1. **Maximize Number of Projects** (`projects`) — Deliver the highest possible number of completed projects within the 60-month horizon.
2. **Alignment Score** (`alignment`) — Maximize the strategic alignment percentage across completed projects.
3. **Utilization of Funds** (`utilization`) — Maximize productive capital deployment while minimizing unspent end-of-programme cash and avoiding sunk costs or insolvency.
4. **Social Benefits** (`benefits`) — Maximize cumulative Benefit Units ($\text{BU}$) generated by completed projects while protecting Annual Recurring Cost ($\text{ARC}$) funding.

### Architectural Components
* **Shared Pure Simulation Engine (`sim-app/src/optimizer/simulationEngine.js`):**
  * Contains the pure, side-effect-free simulation math identical to the main simulator: Beta(2,2) S-curves (`generateSCurve`), compound monthly inflation (`inflator`), periodic tranche funding (`computeReleaseSchedule`), political mandatory lock-ins, approval lag, concurrent project caps, 25%/50%/75% spend milestone risk rolls (`monthRngFor(seed, month)`), Annual Recurring Costs (`ARC`), Social Benefits (`BU`), and multi-objective evaluation (`evaluateRankedObjective`).
* **Hybrid Knapsack + Evolutionary Solver (`sim-app/src/optimizer/optimizerCore.js`):**
  * Combines a 0-1 Dynamic Programming Knapsack seed, 10 goal-tailored heuristic priority orderings, Two-Phase Prefix Budget Reservation + Late-Game Sweep, Genetic Algorithm (Order Crossover + Policy Hyperparameter Mutation), and Local Neighborhood Polishing against the **exact run seed**.
* **Background Web Worker (`sim-app/src/optimizer/optimizer.worker.js`):**
  * Runs 250–300+ full 60-month rollouts off the React main thread in `< 1 second`, emitting `PROGRESS_UPDATE` and `OPTIMIZATION_COMPLETE` messages.
* **React Hook (`sim-app/src/optimizer/usePortfolioOptimizer.js`):**
  * Manages worker lifecycle, progress state, cancellation, and fallback execution.
* **Setup & Playback UI (`sim-app/src/optimizer/OptimizerModals.jsx` & `sim-app/src/App.jsx`):**
  * **Goal Priority Ranking Selector** on the **Setup Screen** (in Custom Mode).
  * **Solver Discovery Modal** with live rollout progress and ranked goal achievement cards.
  * **Live Visual Auto-Play (`AutoPlayControlBar`)** that plays the simulation month-by-month (`1×`, `3×`, `10×`, `Pause`, `Step`, `Skip to End`, or `Manual Takeover`) with live decision rationale badges.
  * **Optimal Strategy Report Modal (`OptimalStrategyReportModal`)** with 5-phase project rollout tables, a month-by-month decision playbook with rationales, excluded-project analysis, and `.xlsx` Excel export.

## 2. Ranked Multi-Objective Function

On the Setup Screen in **Custom Mode**, the user orders the 4 goals $[R_1, R_2, R_3, R_4]$ from **#1 (Highest Priority)** to **#4 (Lowest Priority)**. Each rank is assigned a hierarchical weight:

$$w = [0.55,\; 0.24,\; 0.13,\; 0.08]$$

For any terminal 60-month state, each goal is normalized to a $[0, 100+]$ index:

1. **Projects Index ($G_{\text{projects}}$):**
   $$G_{\text{projects}} = \min\left(115,\; \frac{N_{\text{completed}}}{N_{\text{maxComp}}} \times 100\right)$$
2. **Alignment Index ($G_{\text{alignment}}$):**
   $$G_{\text{alignment}} = \left(\frac{1}{N_{\text{completed}}} \sum_{p \in \text{completed}} \text{Alignment}_p\right) \cdot \min\left(1,\; \frac{N_{\text{completed}}}{N_{\text{minViable}}}\right) \times 100$$
3. **Utilization of Funds Index ($G_{\text{utilization}}$):**
   $$G_{\text{utilization}} = \left(1 - \frac{\text{UnspentCash} + \text{AbandonedSunkCost}}{\text{TotalBudget}}\right) \times 100$$
4. **Social Benefits Index ($G_{\text{benefits}}$):**
   $$G_{\text{benefits}} = \left(0.70 \cdot \frac{\text{RealizedBU}}{0.72 \cdot \text{MaxTheoreticalBU}} + 0.30 \cdot \frac{\text{RealizedBU}}{\text{PotentialBU}}\right) \times 100$$

The composite objective maximized by the solver is:

$$\text{Objective} = \sum_{k=1}^{4} w_k \cdot G_{R_k} - \text{Penalties} + 0.08 \cdot \text{OfficialSimScore}$$

where $\text{Penalties} = 65 \cdot \mathbb{I}_{\text{insolvent}} + 4.5 \cdot N_{\text{abandoned}} + 3.0 \cdot N_{\text{expired}} + 2.0 \cdot N_{\text{arcReductions}}$.

## 3. Three-Phase Optimization Algorithm (`optimizerCore.js`)

1. **Phase 1 — Heuristic & 0-1 Knapsack DP Grid Search:**
   * Generates 10 priority orderings (including a discretized 0-1 Dynamic Programming Knapsack solver and rank-weighted value-density sortings) crossed with 7 policy templates controlling lookahead horizons, prefix budget reservations, alignment floors, crash-start allowances, and late-game surplus acceleration.
2. **Phase 2 — Genetic Algorithm Evolution:**
   * Evolves chromosomes `{ order, skipSet, params }` using tournament selection, Order Crossover (OX), priority swap mutations, and policy hyperparameter mutations.
   * During each rollout, a rolling-horizon cash-flow lookahead (`checkLookaheadFeasibility`) verifies multi-tranche S-curve and ARC affordability before initiating projects, rescues shock-delayed projects via `speedProject`, and prevents shortfalls via `slowProject` / `suspendProject`.
3. **Phase 3 — Local Neighborhood Polishing & Deterministic Verification:**
   * Perturbs the best discovered schedule via adjacent priority swaps and budget envelope fine-tuning, then verifies 100% deterministic replay equivalence using `replayActionPlan(initialSim, bestActionPlan)`.
